Lentera Rimba (Jungle Lantern) is an original arcade game: you are a lantern spirit in a misty forest at dusk, and your light is your life. Collect light orbs to feed the lantern, dodge shadow wisps that drain it, and dash straight through wisps for bonus points. Orbs near wisps are worth more, power-ups grant a shield, a light magnet, or slow time, and every level brings faster, more numerous wisps until dawn breaks. Keyboard and mouse, procedural WebAudio sound, no assets and no network — the whole game is plain static files under `game/`.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or the arrow keys, dash with Space, pause with P, mute with M.
